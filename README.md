# Nyx

### Decentralized Anonymous Chat

Nyx is a decentralized chat application that enables anonymous communication using blockchain-based authentication instead of traditional login systems.

Users connect via wallet addresses, eliminating the need for emails or passwords while maintaining privacy and control over identity.

## Features

- Wallet-based authentication (no traditional login)
- Anonymous 1:1 and room-based chat
- End-to-end encrypted conversations
- Room creation and participation using Solana (SOL) micro-payments
- User blocking and access control
- Event-driven backend with real-time messaging
- Redis-powered pub/sub and caching

## Tech Stack

- **Frontend:** Tanstack Start
- **Backend:** Hono + Bun
- **Database:** PostgreSQL + Drizzle ORM
- **Cache & Pub/Sub:** Redis
- **Blockchain:** Solana

Backend architecture and delivery docs live in [server/docs](./server/docs).

## Philosophy

Nyx is built around privacy, decentralization, and censorship resistance.  
No identities. No tracking. Just communication.
